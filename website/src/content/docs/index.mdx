<h2 class="vc-section">Network settings, without the desktop environment</h2>
<p class="vc-section-lead">The settings panel GNOME and KDE users take for granted, for the desktops that leave it to you.</p>

<CardGrid>
  <Card title="Connect in a keystroke" icon="rocket">
    Search, pick, press Enter. Passwords are asked for when needed and kept in your keyring, only for you.
  </Card>
  <Card title="Every setting" icon="setting">
    Security up to WPA Enterprise, IPv4 and IPv6, DNS, routes, MAC address randomisation, metered, auto-connect priority.
  </Card>
  <Card title="WireGuard built in" icon="seti:lock">
    Create tunnels, edit peers, or import a <code>.conf</code>. OpenVPN and others show up when their NetworkManager plugin is installed.
  </Card>
  <Card title="Your wallpaper's colours" icon="seti:image">
    Reads matugen palettes, ML4W's included, and recolours itself live when you change wallpaper.
  </Card>
  <Card title="Made for Hyprland" icon="laptop">
    A normal window with the class <code>ch.giosuel.Vinculum</code> for window rules, keyboard-driven, with a tray icon and quick popup.
  </Card>
  <Card title="Leaves your settings alone" icon="approve-check">
    Edits change only what you touched, so options from other tools and VPN plugins survive. Works alongside <code>nmcli</code> and <code>nmtui</code>.
  </Card>
</CardGrid>

<h2 class="vc-section">Up and running in minutes</h2>
<p class="vc-section-lead">All it needs is NetworkManager, which your system most likely runs already.</p>

<div class="vc-steps">
  <div class="vc-step">
    <span class="vc-step__n">1</span>
    <h3>Install it</h3>
    <p>From the AUR, as a <code>.deb</code> or <code>.rpm</code>, or as an AppImage, for x86-64 and ARM64. See <a href="/install/">Installing</a>.</p>
  </div>
  <div class="vc-step">
    <span class="vc-step__n">2</span>
    <h3>Float it</h3>
    <p>Add a window rule and a keybind, so it opens where you want it. See <a href="/guide/hyprland/">Hyprland</a>.</p>
  </div>
  <div class="vc-step">
    <span class="vc-step__n">3</span>
    <h3>Connect</h3>
    <p>Pick a network, type the password once. Vinculum picks up the connections you already have.</p>
  </div>
